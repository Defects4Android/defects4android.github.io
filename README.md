# Defects4Android Website

Source for [defects4android.github.io](https://defects4android.github.io) — a dataset browser for the Defects4Android benchmark.

## Stack

- Vue 3 + Vite
- Vue Router (hash mode)
- diff2html for patch rendering

## Development

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` automatically build and deploy via GitHub Actions.
